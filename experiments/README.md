# Experimental Datasets & Testing Protocols

This directory contains empirical testing data, comparative nutrient logs, and scientific analysis for the **Ergonomic Compost Maker (ECM)** project.

---

## 📂 Files Included

* [`npk_decomposition_data.csv`](./npk_decomposition_data.csv) – Machine-readable raw dataset containing baseline soil readings, additive types, post-decomposition NPK values, internal temperatures, and relative humidity.
* [`compost_nutrient_analysis.md`](./compost_nutrient_analysis.md) – Comprehensive agronomic explanation of decomposition trends, microbial kinetics, and carbon-to-nitrogen ($C:N$) dynamics.

---

## 🧪 Testing Protocol Summary

1. **Air Calibration Verification:** Sensor probe suspended in atmospheric air to confirm baseline readings of $0-0-0\,mg/kg$.
2. **Homogenized Base Testing:** Stable soil moisture established at $\sim 55-60\%$ RH to ensure consistent galvanic contact across the stainless steel probe prongs.
3. **Feedstock Dispersion:** 100g of blended feedstock thoroughly mixed into 500g of base soil using the ECM internal rotary agitator.
4. **Data Acquisition:** Measurements logged after a thermal equilibration window of 30 minutes, repeated across multiple daily cycles.
